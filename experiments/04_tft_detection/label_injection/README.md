# 已废弃：异常注入与 LightGBM 路线

本目录只保存毕业设计研究过程中尝试过、后来完全放弃的对照方案，不属于论文最终方法，也不会被默认训练、检测或归因入口调用。

## 路线用途

- 人工生成点异常、集体异常和跨通道异常；
- 为 LightGBM 分类器构造标签或注入样本；
- 支持早期 LOSO、监督分类等对照实验。

## 当前文件

- `build_label_v2.py`：第二版异常注入生成器。当前仍依赖外部 `build_label.py`，且文件末尾引用了未定义的 `InjectionPipeline`，因此只作为研究过程存档，不保证独立运行。

## 与最终方案的边界

论文最终路线使用 TFT 分位数预测、偏差信号、统计规则与自适应状态机，不使用本目录生成的监督标签，也不使用 LightGBM。该目录不会加入正式运行入口，相关依赖也不会加入默认安装列表。
