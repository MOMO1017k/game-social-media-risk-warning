# 时序分解与合成原始模块

这里保存毕业设计研究阶段的原始实现，文件名与原始 Notebook 的步骤编号保持一致，便于追溯实验过程。

当前代码覆盖分布检验、数据变换、Prophet 趋势与周期分解、官方事件冲击、AR 自相关、GARCH 波动率、残差清洗，以及逆向合成的相关噪声、波动率、AR、事件、季节性和逆变换步骤。

这些文件暂时不能视为独立可运行的软件包：Notebook 中还存在更新版函数和关键辅助函数，步骤间主要依赖内存对象，路径与日期也尚未配置化。完整问题清单见 `docs/03_decomposition_synthesis_review.md`。

编号中的 `step1_6.py` 缺失目前判断为研究期编号跳跃，而不是论文方法缺失：`step1_5.py` 之后直接由 `step1_7.py` 完成标准化残差清洗、相关矩阵估计和边缘分布拟合。正式重构时会改用语义化模块名，不再沿用这一编号。
